Defenses
Ablative Armour: armour HP's are divided evenly around the ships hull, arranged into blocks (e.g. a battleship has armour blocks on each of top, bottom, port, starboard and 4 on fore and aft on the aft, this is 32 blocks in total. It has 1,200,000 armour HP, so each block has 37500 HP).
Other ship types have proportionately few blocks (less area to cover) and, usually, less HP per block (thinner).

Flicker Shields, % chance to block each attack. Capital ships have 6 Flicker shields (fore, aft, top, bottom, port, starbpard), Cruisers have 4 (each ship covers one side and the respective top and bottom), Destroyers have 2 (port and starboard), Corvettes have 1 (covers entire ship). Each successful block reduces % by 0.1, flicker shields regain 1% each at the end of the round. Flicker shields can block railgun slugs but some of kinetic energy is still transferred so a successful block reduces damage by 75%.
Battle ships have 60% block chance
Battle Cruisers have 57% block chance
Heavy Cruisers have 54% block chance
Light Cruisers have 51% block chance
Destroyers have 48% block chance
Corvettes have 45% block chance

Hit Points
Ships have 1 HP for each tonne of mass. To integrate this with the air combat game change 1 to what would be an appropriate value for a 1 tonne aircraft (e.g. if a 1 tonne aircraft has a total 100 HP then use 100 HP/tonne of mass). These HPs are divided between major systems. Each system on a ship has a two digit number showing which armour block it is behind (from 1-32) and how deep it is (from 1-X). When an armour block is gone the system with the lowest depth behind that block takes the hit. Ships systems are much less dense than armour so any single hit of XX% or more of the systems starting HP deals that XX% to the system then penetrates on to deliver the remaining damage to the next system inwards.
XX% depends on the density of the system, dense systems such as engines have higher XX values, say 30%, whereas lower density systems, such as habitation spaces have low values, say 10%.
If damage penetrates the deepest system it is assigned to the ships Excess Damage pool, which is 5% of the ships starting HP. When the excess damage pool is zeroed the ship falls apart in a shower of wreckage, but no explosion.
Systems which have multiple elements (such as missile arrays, laser banks, fighter bays, lose a number of elements equal to the total % damage they taken, always assume empty cells are destroyed first for missiles).
Reactors have a chance of going critical and destroying the ship when they take damage. The chance is 1/10th of the total damage they have taken, rolled each time they take damage.

## 3. Block–Depth coding (how to actually place systems)

You said:

> Each system on a ship has a two digit number showing which armour block it is behind (from 1–32) and how deep it is (from 1–X).

Here’s a **simple pattern** you can use for *all* classes:

* Treat the hull as a cylinder sliced into:

  * **Fore half:** blocks 01–16
  * **Aft half:** blocks 17–32
* Within each half, group by “face”:

  * Dorsal (top): 4 blocks
  * Ventral (bottom): 4 blocks
  * Port: 4 blocks
  * Starboard: 4 blocks

Example (Battleship):

* **Prow lasers**: put banks behind **fore blocks 01–08**, depth **1–2**.
  e.g. “Prow Laser Bank 1 – HP 5,625 – Block 01 – Depth 1 → Code 01–1”
* **Stern lasers**: aft blocks **17–24**, depth **1–2**.
* **Port broadsides**: fore port **09–12** and aft port **25–28**, depth 1.
* **Starboard broadsides**: fore starboard **13–16** and aft starboard **29–32**, depth 1.
* **Missile arrays / PD turrets**: ring them around outer layers at depth 1–2, sharing the same blocks as adjacent laser banks.
* **Reactors / engines**: cluster behind aft blocks (e.g. 21–32) at **depth 3–4**, so they’re “deep” targets.
* **CIC / Flag bridge**: behind **fore dorsal blocks 01–04**, depths **3–4**.
* **Main bridge / Aux bridge**: shallower dorsal blocks (01–04) at **depth 2–3**.
* **Fighter bays**: mid-ship port/starboard blocks around **09–16 / 25–32**, depths **1–2**.
* **Marines barracks**: central, behind mid fore or aft blocks at moderate depth (e.g. 10–3).
* **Cargo**: aft ventral blocks at low–moderate depth.

For **smaller ships**, you:

* Use fewer blocks (e.g. only 8 or 12 of the 32 positions are “live”),
* Keep the same notion:

  * prow/cockpit → low-number fore blocks,
  * engines → high-number aft blocks,
  * broadsides → mid-port/starboard,
  * sensors on dorsal/ventral fore/aft, etc.

### How to use this at the table

* When a hit penetrates a given **armour block**, you:

  1. Look up all systems using that block.
  2. Choose the **shallowest depth** system that still has HP (as per your rules).
  3. Apply damage; if it exceeds your “penetration %” threshold for that system type, spill the rest inward (next depth).

* Because I’ve given you **block ranges** for grouped entries (e.g. “05–08”), you can:

  * Either treat each block within that range as holding *one* copy of that system; or
  * Roll a 1–N to pick which of those blocks is actually involved if you’re resolving very precisely.

If you’d like, I can now do a **compact master table** with rows = ship class and columns = “# broadside banks, HP per; # missile arrays, HP per; # CIWS, HP per; etc.”, using these same numbers, as a quick reference sheet separate from the block/depth detail.
